# AGENTS.md — Code Conventions

## Python

- License statement at the top of every Python file (see existing files)
- Follow scientific Python conventions (naming, structure, docstrings)
- Type annotations required on all function signatures
- Arguments: most generic type (`Sequence`, `Mapping` from `collections.abc`);
  returns: most specific type
- Prefer `dbetto.AttrsDict` over plain `dict` for frequently queried
  non-trivial dictionaries (enables attribute-style access)
- `dbetto.TextDB.on()` and `LegendMetadata.channelmap()` trigger filesystem
  queries — avoid repeated calls at Snakemake DAG build time; cache instead

## Dependencies & Tooling

- Python package; see `pyproject.toml` for deps, build config, and Pixi config
- ALWAYS run commands via `pixi run`
- ALWAYS use `python3`, never `python`

## Linting & Pre-commit

- Formatting/linting enforced by pre-commit (hooks in
  `.pre-commit-config.yaml`, config in `pyproject.toml`)
- DO NOT run pre-commit unless explicitly asked by the user.
- Default: run `pre-commit` only on modified files
- When handling commit/push: run `pre-commit run --all-files`

## Git Workflow

- Commit style: Conventional Commits (https://www.conventionalcommits.org)
- **No AI authorship in commit messages** — no "generated by AI",
  "Co-authored-by: Claude", or similar
- **NEVER commit without first running pre-commit and the relevant test suite
  and verifying they pass.** No exceptions
- PRs: require passing CI; include concise description and link related
  PRs/issues

## Statistics & Uncertainty

- **Bayesian approach** for all analyses and uncertainty calculations
- Binomial efficiencies: Beta conjugate prior (Jeffrey's, `Beta(0.5, 0.5)`);
  report posterior mean ± posterior standard deviation
